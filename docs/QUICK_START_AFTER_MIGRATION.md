## 🚨 常见问题

### Q1: 分析延迟超过10秒怎么办？

**原因**:
- 数据量过大（>200期）
- 健康监控计算开销
- 数据库查询慢

**解决方案**:
1. 监控具体慢在哪一步（查看日志）
2. 考虑异步健康监控
3. 优化数据库查询

### Q2: 飞书告警格式变了如何恢复？

**新格式包含**:
- Old + New 协整检验对比
- OLS参数（α, β）
- 健康监控（仅4h）

**如需恢复旧格式**:
修改 `realtime_kline_service.py` 的 `_send_alert` 函数

### Q3: 数据点不足导致分析失败？

**旧版**: 最少30个点
**新版**: 最少100个点

**解决方案**:
1. 等待数据累积到100个点
2. 或在 `realtime_kline_service.py` 中调低 `beta_window`（不推荐）

### Q4: 如何回滚到旧版？

**Git回滚**:
```bash
git log --oneline -10
git revert <commit-hash>
```

**或从 Git 历史恢复删除的函数**
